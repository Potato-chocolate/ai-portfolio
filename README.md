## 1. AI_TOP_100 [2026]

카카오임팩트가 주최하고 과학기술정보통신부와 카카오가 후원한 AI 활용 경진대회입니다. 올해는 참가자가 AI 에이전트를 설계하고 운영하는 역량을 평가했습니다.

### 예선: 업무 API와 연동하는 메신저 챗봇 에이전트

가상 마을 관계자를 인터뷰해 업무 규칙을 찾고, 그 규칙대로 응대하는 챗봇 에이전트를 만들었습니다.

**구조**

```
메시지 수신(웹훅) → 즉시 응답 → 비동기 처리
  → Claude 도구 호출 루프(업무 API 조회·접수) → 답변 전송
```

- **도구 자동 생성**: OpenAPI 형식의 API 명세를 읽어 엔드포인트 하나를 도구 하나로 변환하는 생성기를 만들었습니다. 명세 파일만 바꾸면 도구 목록이 다시 만들어집니다.
- **보안**
  - 사용자 입력과 API 결과를 태그로 감싸 지시가 아닌 데이터로만 다뤘습니다.
  - 시스템 프롬프트에 감지용 문자열(canary)을 넣어, 답변에 나오면 전송을 막았습니다.
  - 상태를 바꾸는 요청은 결과를 모를 때 자동 재시도하지 않아 이중 접수를 막았습니다.
  - 웹훅 요청은 비밀 헤더로 검증하고, 비밀값이 설정되지 않으면 서버가 아예 뜨지 않게 했습니다. 키는 환경변수로만 관리했습니다.
- **배포·운영**: 고정 IP 클라우드 VM에 Docker와 HTTPS로 배포했습니다. 재부팅 후 자동 복구를 확인했고, 자동 테스트와 실제 모델 리허설 스크립트로 배포 전에 점검했습니다.
- **대회 당일**: 서버와 배포 구조는 대회 전에 준비했습니다. 당일에는 인터뷰에서 나온 업무 규칙을 지식 문서로 정리해 반영하고, 시험한 뒤 다시 배포했습니다.
- **결과**: 심사 기간 동안 코드 변경 없이 운영했고, 예선을 통과해 본선에 진출했습니다.

### 본선: 3D 가상 월드 자율 에이전트 (현장, 3라운드)

예선의 마을을 3D 가상 월드로 확장한 무대에서, 에이전트가 마을의 과제를 찾아 해결하는 방식이었습니다. 마지막 라운드 90분은 사람이 손대지 못하고 에이전트가 혼자 움직였습니다.

**구조**

- **지휘 에이전트 1개(Claude Code)**: 판단과 실행을 맡고, 기록 정리 같은 잡무는 보조 에이전트에 나눠 맡겼습니다. 다시 낼 수 없는 제출은 다른 모델(Codex)과 판정이 일치할 때만 내도록 규칙을 정해 두었습니다.
- **직접 만든 Python 도구**
  - 호출 래퍼: 여러 호출을 묶어 실행하고, 모든 호출을 기록하며, 한 단계가 실패하면 남은 단계를 멈춥니다.
  - 경로 실행기: 단계마다 실제 상태를 다시 확인한 뒤 다음 단계를 계산합니다.
  - 탐색기: 깊이 우선 탐색과 호출 상한을 둡니다. 가짜 환경으로 단위 테스트를 통과시킨 뒤 사용했습니다.
  - 기록 요약 도구: 호출 기록을 상태 파일로 요약합니다.
- **기억**: 진행 상황·지침·작업 기록을 상태 파일 하나에 두었습니다. 대화가 압축되거나 끊겨도 이 파일로 이어갔습니다.
- **무인 운영**: 몇 분마다 예약 작업이 에이전트를 깨워 스스로 점검하게 했습니다. 진행 변화, 같은 실수의 반복, 작업별 시간 상한, 마감을 확인합니다.

**실패에서 고친 것**

| 문제 | 고친 방법 |
|---|---|
| 실패한 단계 뒤에도 다음 단계를 실행해 상황이 꼬임 | 실패하면 래퍼가 남은 단계를 즉시 멈추게 수정 |
| 검증하지 않은 경로를 계획에 넣어 실패 | 기록으로 확인된 구간만 쓰도록 지침과 경로 목록을 바꿈 |
| 여러 일을 오가며 시간 낭비 | "한 번에 하나, 끝까지"와 작업별 시간 상한을 지침에 추가 |
| "절대 하지 않는다" 규칙이 더 큰 기회를 막음 | 규칙에 예외 조건을 미리 적어 두기로 함 |

**배운 것**: 사람이 손을 뗀 뒤에는 도구를 일 단위로 감싸 두는 것과 기억을 파일에 남기는 것이 가장 중요했습니다. 절대 규칙에는 예외 조건을 함께 적어야 한다는 것도 배웠습니다.

## 일하는 방식

- **검증 먼저**: 제출물의 수치와 사실은 원문 출처와 대조하고, 중요한 산출물은 다른 모델에게 따로 검수하게 합니다.
- **보안 기본값**: 비밀값은 환경변수로만 다루고 저장소에 올리지 않습니다. 사용자 입력과 외부 데이터는 지시가 아닌 데이터로 취급하고, 설정이 빠지면 안전한 쪽으로 멈추게 만듭니다.
- **기록으로 잇기**: 작업 상태와 결정 이유를 파일에 남겨, 세션이 끊겨도 다음 작업이 이어지게 합니다.
